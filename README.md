# หลักสูตร Nim Programming: จากศูนย์สู่ระดับโลก

## ภาพรวมหลักสูตร

หลักสูตรนี้ครอบคลุมการเขียนโปรแกรมด้วยภาษา Nim ตั้งแต่ระดับพื้นฐานจนถึงระดับมืออาชีพและระดับโลก รวมถึงการพัฒนาเว็บแอปพลิเคชัน, Malware Development, และ AV Evasion Techniques

## โครงสร้างหลักสูตร

### ส่วนที่ 1: พื้นฐาน Nim (Parts 1-30)
- การติดตั้งและตั้งค่า
- ไวยากรณ์พื้นฐาน
- ประเภทข้อมูล
- การควบคุมการทำงาน
- ฟังก์ชัน
- Arrays, Sequences, Tables
- Strings และการจัดการข้อความ
- Input/Output
- การจัดการไฟล์
- Error Handling

### ส่วนที่ 2: Nim ระดับกลาง (Parts 31-60)
- Object-Oriented Programming
- Generics
- Macros และ Templates
- การจัดการหน่วยความจำ
- Concurrency และ Parallelism
- Foreign Function Interface (FFI)
- การเชื่อมต่อกับ C/C++
- Modules และ Packages
- Testing
- Debugging

### ส่วนที่ 3: Nim ระดับสูง (Parts 61-80)
- Advanced Macros
- Compile-time computation
- DSL Creation
- Memory-mapped I/O
- Low-level programming
- Optimization techniques
- Cross-compilation
- Embedding Nim

### ส่วนที่ 4: Web Development ด้วย Nim (Parts 81-100)
- HTTP Servers
- REST APIs
- WebSockets
- Database Integration
- Authentication
- Deployment

### ส่วนที่ 5: Malware Development & Security (Parts 101-150)
- Windows Internals
- Process Injection
- Shellcode Execution
- AV/EDR Evasion
- Post-exploitation
- Advanced Techniques

### ส่วนที่ 6: ระดับโลก (Parts 151-200+)
- Advanced Exploitation
- Custom C2 Framework
- Advanced Evasion
- Kernel Exploitation
- Anti-forensics

## การใช้งานหลักสูตร

```bash
# ติดตั้ง Nim
curl https://nim-lang.org/choosenim/init.sh -sSf | sh

# หรือใช้ choosenim
choosenin 2.0.0

# ตรวจสอบเวอร์ชัน
nim --version
```
