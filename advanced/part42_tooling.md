# Part 42: Nim Tooling - เครื่องมือพัฒนา

## Nim Tools Overview

```
nim           - ตัว compiler
nimble        - package manager + task runner
nimpretty     - code formatter
nimgrep       - pattern search tool
nimfind       - find usages/definitions
nimsuggest    - IDE integration (LSP)
nimprof       - profiler
nimcheck      - type checker เหมือน `nim check`
```

## Nimble - Package Manager

```bash
# Search packages
nimble search jester
nimble search "json parser"

# Install package
nimble install jester
nimble install jester@0.5.0  # specific version

# Update all packages
nimble refresh     # update package list
nimble upgrade     # upgrade installed

# List installed
nimble list --installed

# Uninstall
nimble uninstall jester

# Create new project
nimble init myproject
nimble init --kind=lib mylib  # library
nimble init --kind=bin myapp  # binary

# Publish to nimble registry
nimble publish

# Development mode (link instead of copy)
nimble develop

# Lock dependencies
nimble lock
nimble install  # installs from lock file
```

## nimpretty - Code Formatter

```bash
# Format files
nimpretty myfile.nim
nimpretty --indent:2 myfile.nim   # 2-space indent
nimpretty --maxLineLen:100 myfile.nim

# Format entire project
find . -name "*.nim" -exec nimpretty {} \;

# Check without modifying (CI)
nimpretty --check myfile.nim
```

```nim
# .editorconfig สำหรับ Nim
# [*.nim]
# indent_style = space
# indent_size = 2
# end_of_line = lf
# charset = utf-8
# trim_trailing_whitespace = true
# insert_final_newline = true

# Formatting conventions:
proc goodStyle*(x: int, y: int): string =
  ## Nim style: 2-space indent, no trailing spaces
  let result = x + y
  $result

proc alsoGood*(items: seq[string]): int =
  for item in items:
    if item.len > 0:
      inc result
```

## nimsuggest - LSP / IDE Integration

```bash
# Start nimsuggest server
nimsuggest myproject.nim

# Features:
# - goto definition
# - autocompletion
# - error checking in real-time
# - hover information
# - rename symbol

# VS Code: install nim extension
# JetBrains: install NimPlugin
# Vim/Neovim: nimlsp or coc-nim
# Emacs: nim-mode

# nimsuggest commands (from IDE plugins):
# sug   - suggestions at point
# con   - context (symbol info)
# def   - goto definition
# use   - find usages
# dus   - definition + usages
# chk   - check file
# highlight - syntax highlight info
# outline  - document outline
```

## nim check และ การตรวจสอบ Type

```bash
# Type check without compiling
nim check myfile.nim

# Strict checks
nim check --styleCheck:error myfile.nim  # enforce naming style
nim check --styleCheck:hint myfile.nim   # hints only

# Warning flags
nim c --warning[UnusedImport]:on myfile.nim
nim c --warning[Deprecated]:on myfile.nim
nim c --hint[Performance]:on myfile.nim

# Enable all warnings
nim c --warnings:on --hints:on myfile.nim
```

## nimgrep - Search Tool

```bash
# Search for pattern in Nim files
nimgrep pattern *.nim
nimgrep --recursive pattern src/

# Search for identifier
nimgrep --word myVariable *.nim

# Replace
nimgrep --replace newName oldName *.nim

# Regex
nimgrep --re "proc \w+\*" *.nim
```

## profiling และ Optimization

```bash
# Build with profiling
nim c --profiler:on --stackTrace:on myapp.nim
./myapp
# Outputs: profile_results.txt

# Memory profiler
nim c --profiler:on --d:memProfiler myapp.nim

# Valgrind (Linux)
nim c --debugger:native myapp.nim
valgrind --tool=callgrind ./myapp
callgrind_annotate callgrind.out.*
```

## CI/CD Pipeline

```yaml
# .github/workflows/nim.yml
name: Nim CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Nim
        uses: jiro4989/setup-nim-action@v1
        with:
          nim-version: 'stable'
      
      - name: Install dependencies
        run: nimble install -y
      
      - name: Check code style
        run: nimble lint
      
      - name: Run tests
        run: nimble test
      
      - name: Build release
        run: nimble release
  
  build-matrix:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: jiro4989/setup-nim-action@v1
      - run: nimble install -y
      - run: nimble test
```

```nim
#     }
#   }

# Install from lock file:
# nimble install

# Update a specific package:
# nimble update jester
# nimble lock  # regenerate lock file
```
